# 42 Reset

[Accueil](README.md) · **Français** · [English](README.en.md) · [Español](README.es.md)

## À quoi ça sert ?

Parfois, ton profil 42 ne s’ouvre plus. Effacer les données du site dans le navigateur peut aider à le faire fonctionner à nouveau.

42 Reset fait ce nettoyage en un clic pour ces deux sites :

- [L’Intra 42](https://intra.42.fr/)
- [Le profil 42](https://profile.intra.42.fr/)

Le navigateur garde des fichiers pour afficher les pages plus vite : c’est le **cache**. Il garde aussi de petites informations, appelées **cookies**, qui peuvent servir à te garder connecté.

Si ces données posent problème, l’extension les efface pour repartir de zéro. Elle ne peut pas réparer une panne des serveurs de 42 ou un problème de connexion Internet.

## Comment l’installer ?

1. Télécharge le projet. Si tu as un fichier ZIP, décompresse-le dans un dossier que tu garderas sur ton ordinateur.
2. Ouvre Brave ou Google Chrome.
3. Dans la barre d’adresse, écris `brave://extensions` pour Brave ou `chrome://extensions` pour Chrome.
4. Active **Mode développeur**, en haut à droite.
5. Clique sur **Charger l’extension non empaquetée**. Le bouton peut aussi s’appeler **Charger l’extension décompressée** ou **Load unpacked**.
6. Sélectionne le dossier qui contient le fichier `manifest.json`.
7. Dans le menu des extensions, près de la barre d’adresse, épingle **42 Reset** pour retrouver facilement son bouton.

Garde le dossier à sa place après l’installation. Le navigateur en a besoin pour faire fonctionner l’extension.

## Comment l’utiliser ?

1. Enregistre ce que tu es en train d’écrire sur l’Intra, car ses pages vont être rechargées.
2. Clique une fois sur le bouton **42 Reset**.
3. Attends la fin du nettoyage. Les pages de l’Intra déjà ouvertes se rechargent automatiquement.
4. Reconnecte-toi à 42 si le site te le demande.

Si aucune page de l’Intra n’était ouverte, ouvre ton profil après le nettoyage.

Si un **!** apparaît sur le bouton, le nettoyage n’est pas terminé correctement. Place la souris dessus pour lire le message, puis clique pour réessayer.

## Qu’est-ce qui est effacé ?

L’extension efface les cookies, le cache et les autres données que ces deux sites ont enregistrées dans ton navigateur.

Cela peut te déconnecter de l’Intra et d’autres services 42 qui utilisent les mêmes cookies. Certains réglages du site peuvent aussi être oubliés.

Tes mots de passe enregistrés dans le navigateur, tes favoris et ton historique sont conservés. Ton compte, tes projets et ta progression sur les serveurs de 42 restent en place.

Le nettoyage agit dans le navigateur et le profil où l’extension est installée. Il ne fonctionne pas en navigation privée.

## Sur quels ordinateurs ?

Utilise une version récente de Brave ou de Google Chrome sur ordinateur. Le projet est prévu pour Linux, Windows et macOS. Pour le moment, il a été testé dans Brave sous Linux.

## Si ça ne marche toujours pas

- Si le navigateur ne trouve pas l’extension, vérifie que tu as choisi le dossier contenant `manifest.json`, et non le fichier ZIP.
- Si le nettoyage semble bloqué, retourne sur la page des extensions et clique sur **Recharger** pour 42 Reset, puis réessaie.
- Si le profil ne s’ouvre toujours pas après le nettoyage, vérifie ta connexion Internet. Tu peux aussi demander de l’aide au support 42.

Le site peut enregistrer de nouvelles données après ton retour : c’est normal. Si le problème revient, tu peux refaire le nettoyage.

## Mise à jour ou suppression

Pour mettre à jour l’extension, remplace ses fichiers dans le même dossier, puis clique sur **Recharger** depuis la page des extensions.

Pour la désinstaller, clique sur **Supprimer** sur cette même page.
